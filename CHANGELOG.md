# Changelog

## 1.0.1 — 2026-10-13

- Keep the visible contrast result cleared while either color input is invalid.
- Apply the selected normal or large text thresholds to every palette swatch; show a neutral result when the background is invalid.
- Add WCAG math tests, a Node.js 20/22/24 CI matrix, and automated release ZIP/checksum publishing.

## 1.0.0 — 2026-10-08

- First public release of ContrastKit.
- Added WCAG 2.2 contrast ratio and AA/AAA status for normal and large text.
- Added color pickers, live preview, and foreground/background swapping.
- Added editable palettes with individual AA/AAA results.
- Added CSS custom property export, clipboard copy, and dark theme.
- Documented color format, privacy, accessibility thresholds, and limitations.
