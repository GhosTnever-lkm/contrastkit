# Changelog

## 1.0.2 — 2026-10-13

- Apply normal or large text thresholds to every palette swatch.
- Show neutral palette results when the background color is invalid.
- Add a regression test for normal and large text thresholds.

## 1.0.1 — 2026-10-11

- Extract WCAG color normalization and contrast math into a testable module.
- Add reference-ratio tests and a CI workflow; load the app as an ES module.
- Refresh the version and download instructions.

## 1.0.0 — 2026-10-08

- First public release of ContrastKit.
- Added WCAG 2.2 contrast ratio and AA/AAA status for normal and large text.
- Added color pickers, live preview, and foreground/background swapping.
- Added editable palettes with individual AA/AAA results.
- Added CSS custom property export, clipboard copy, and dark theme.
- Documented color format, privacy, accessibility thresholds, and limitations.
